电商购买意图建模 · PR-AUC 0.729 / AIPW +1.59pp

问题：购买会话只占 15.47%，准确率会虚高；要识别高意向会话，并把预测与周末因果效应分开。

方法：分层 80/20、五折 CV、PR-AUC、Pipeline 防泄漏、折外阈值 0.415、SHAP、IPW/AIPW，以及移除 PageValues 的稳健性检查。

结果：RandomForest 测试集 PR-AUC 0.7290、ROC-AUC 0.9199、F1 0.6614；AIPW 周末效应 +1.59pp（95% CI [+0.03, +3.10]）。

全面二孩政策复现 · CFPS/CHFS + PSM-DID

问题：全面二孩政策是否改变家庭时间偏好，并进一步影响储蓄—消费结构。

方法：CFPS 2010–2020、CHFS 2013–2019；跨期消费欧拉方程测算时间偏好率；Logit 倾向得分 + 1:1 匹配 + DID；复现四组准实验；Stata 清洗。

结果：复现结果与原文核心方向基本一致：政策降低政策敏感型家庭的时间偏好率，并存在经济脆弱性、健康、预期等异质性。这是复现作业，不声称原创。

哈啰单车调度优化 · 整数规划 + OR-Tools

问题：4 个需求点、3 辆不同容量/运价的车、100 辆单车，在需求上下限和车辆容量约束下优化成本与利润。

方法：决策变量 x_ij；目标函数为需求点利润减运输成本；约束覆盖需求上下限、车辆容量、配送中心往返和非负整数；用 OR-Tools 的 SCIP 求解。

结果：输出每辆车的配送量与路径方案；课程报告结论为降低运输成本、提高利润。报告没有统一的最优值前后对比，不补造百分比。

正大杯 · DeepSeek 智能化普惠调研 · 462 份问卷 / 三端分析 / 全国三等奖

问题：在 AI 崛起背景下，DeepSeek 如何以低成本技术扩散撬动「普惠杠杆」？研究从政府、企业、用户三个层面回答技术崛起如何转化为社会福祉。

方法：线上（文献、爬虫、线上访谈）+ 线下（街采、预调查、正式调查、补充调查）；深度访谈 + Nvivo 编码；Python 爬取小红书/微博；上海 16 区分层抽样，回收 462 份有效问卷；预调查/正式调查做 Cronbach's α 与 KMO/Bartlett 检验。

结果：RFM 聚类做用户分层；随机森林识别分层因素；有序 Logistic 分析付费意愿（性能 OR=1.62, 95% CI [1.32,1.98]；用户体验 OR=0.80；服务支持不显著）；LSTM 做情感分类 + 词云；支付意愿做分组统计。

政府端呈现服务/成本/知识三类普惠；企业端呈现头部效应、行业分化和长尾潜力，接入对股价有正向影响；用户端形成「社交媒体引流 + 新闻权威扩散 + 亲友口碑」的复合传播模式。

成果：60 页研究报告、答辩 PPT、问卷与数据附录；全国三等奖（995 所高校、28 万+ 人报名）。我作为核心组员全程参与研究设计、数据采集、建模和报告撰写。
