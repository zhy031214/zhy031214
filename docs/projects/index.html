每个案例的结构

  1. 背景 / Context — 业务问题是什么，为什么值得做。
  2. 我的工作 / What I did — 我具体做了什么，边界在哪里。
  3. 结果 / Impact — 用时间、覆盖率、采用率等指标说明变化。
  4. 边界 / Limits — 哪些结论不能证明，哪些数据不能公开。
  5. 这个项目说明了什么 / What it shows — 这段经历能说明什么能力。
